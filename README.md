## 🚀 Setup & Run

### Prerequisites
- Git
- A modern web browser
- VS Code or another code editor (optional)

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/HasithaGayan/ai-fullstack-87.git
   ```

2. Enter the repository folder:

```bash
cd ai-fullstack-87
```

3. Open the project in VS Code:

```bash
code .
```

4. Navigate to the tested HTML page:

```text
step-01/day-01/index.html
```

5. Open `index.html` in a modern web browser.

The Day 1 HTML page has been tested successfully from a fresh clone of this repository.
