
# Day 13 - JavaScript Functions

## Learning Goals

Practice JavaScript functions, parameters, return values,
scope, closures, and reusable code.

## Topics Covered

- Function declarations
- Function parameters and arguments
- Return values
- Function expressions
- Arrow functions
- Default parameters
- Early returns
- Global, function, and block scope
- Closures and independent counters
- Refactoring existing JavaScript exercises

## Eight Refactored Exercises

1. Positive, negative, or zero checker
2. Student grade calculator
3. Leap-year checker
4. Sum of numbers
5. Even-number counter
6. Factorial calculator
7. FizzBuzz
8. Prime-number checker

## Testing

Added eight automated checks in script.js.

All eight checks passed during guided testing.

## How to Run

1. Open index.html with VS Code Live Server.
2. Open browser DevTools (F12).
3. Select the Console tab.
4. Review the function examples and test results.

## Files

- index.html - HTML page
- script.js - JavaScript functions and tests
- README.md - Learning notes

## Key Takeaway

Functions help make code reusable and easier to maintain.
Closures allow functions to remember variables from their
surrounding scope.
