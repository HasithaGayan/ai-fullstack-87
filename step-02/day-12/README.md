# Day 12 — JavaScript Conditions and Loops

## Learning Goals

Practice JavaScript control flow, write problem-solving exercises, and understand how loops and conditions work.

## Topics Covered

- `if`, `else if`, and `else`
- `switch` statements
- Ternary operators
- `for` and `while` loops
- `break` and `continue`
- Comparison and logical operators
- Input validation and edge-case handling

## Completed Code

The `script.js` file contains:

- 20 guided control-flow exercise solutions, including FizzBuzz, leap years, grading, factorials, prime numbers, counting, and minimum/maximum calculations.
- Examples tracing a `for` loop and a `while` loop.
- A conditional refactoring example.
- Additional practice with loop increments, running totals, and divisibility.

## How to Run

1. Open `index.html` using VS Code Live Server.
2. Open your browser's Developer Tools.
3. Select the Console tab.
4. Review the output from each exercise.
