
# Day 20 - JavaScript Checkpoint 🚀

## Project Overview

Day 20 is the JavaScript checkpoint of my
87-Day AI + Full-Stack Developer Roadmap.

This checkpoint reviews JavaScript fundamentals,
data structures, debugging, browser APIs,
and project testing.

## JavaScript Practice

Completed 10 guided coding exercises:

1. Format text using trim() and toUpperCase()
2. Find even numbers using filter()
3. Find the largest number using a loop
4. Remove duplicate values using Set
5. Count repeated words using Map
6. Implement linear search
7. Calculate totals using reduce()
8. Count vowels in a string
9. Reverse a string
10. Filter affordable products

## How to Run

1. Open the repository in VS Code.
2. Navigate to step-02/day-20.
3. Open index.html using Live Server.
4. Press F12 and select Console.
5. Review the JavaScript exercise results.
6. Open rebuild.html using Live Server.
7. Test saving, loading, and clearing a task.

## Debugging Example

During the Weather App project, an invalid
API endpoint was used intentionally to
test HTTP error handling.

The application displayed an error message
instead of crashing.

After restoring the correct API endpoint,
weather searches worked again.

## Known Limitations

- The checkpoint exercises run in the browser Console.
- Weather requests require internet access.
- Browser geolocation requires permission.
- localStorage data is stored in the current browser.
- The rebuild is a practice example, not a full task manager.
