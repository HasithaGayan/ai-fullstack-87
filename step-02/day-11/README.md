# Day 11 — JavaScript Fundamentals

## Learning Goals

Practice JavaScript variables, data types, operators, type conversion, and problem-solving.

## What I Learned

- `let` and `const`
- Strings, numbers, booleans, `null`, and `undefined`
- Template literals and `typeof`
- Arithmetic, comparison, and logical operators
- Explicit type conversion with `Number()` and `String()`
- Conditional statements using `if`, `else if`, and `else`

## Completed Work

- 20 small JavaScript exercises
- Console calculator supporting addition, subtraction, multiplication, and division
- Error handling for invalid numbers, unsupported operators, and division by zero

## How to Run

1. Open `index.html` with VS Code Live Server.
2. Open the browser's Developer Tools.
3. Select the Console tab to view the JavaScript output.
4. To test different calculator calculations, edit the three calculator input values in `script.js`, save, and refresh.

## Project Files

- `index.html` — Loads the JavaScript file in the browser.
- `script.js` — Contains the learning examples, exercises, and calculator.

## Testing

Practiced normal calculations and tested invalid-number, invalid-operator, and division-by-zero cases.
