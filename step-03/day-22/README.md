
# Day 22 - Strict TypeScript Task Manager

## Overview

A strict TypeScript implementation of the core
logic from my Day 17 JavaScript Task Manager.

This project is part of my 87-Day AI and
Full-Stack Developer learning roadmap.

## Features

- Add new tasks
- Display all tasks
- Mark tasks as completed
- Delete tasks
- Reject empty task titles
- Handle invalid task IDs
- Validate unknown external data
- Seven automated tests

## Technologies

- TypeScript
- Node.js
- npm
- Node.js Test Runner
- Git and GitHub

## TypeScript Concepts

- Primitive types
- Typed arrays and tuples
- Objects and optional properties
- Typed functions
- Type aliases and interfaces
- Strict mode
- Unknown types
- Type narrowing
- Runtime validation

## Installation

npm install

## Run the Project

npm start

## Available Commands

- npm run build
- npm run check
- npm start
- npm run validate
- npm test

## Testing

Seven automated tests cover task operations,
invalid inputs and external data validation.

## What I Learned

TypeScript helps detect type errors before
execution. However, external data still needs
runtime validation.

I converted JavaScript task management logic
into strict TypeScript without using any.

## Current Limitations

This is a console-based learning project.
Tasks are stored in memory and reset when
the program restarts.

## Status

Core features implemented and tested.
