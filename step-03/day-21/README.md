## What Is a Git Branch?

A Git branch lets developers work on
changes separately from the main branch.

My feature branch:

feature/day-21-workflow

## Git Commands

Check the current branch:

git branch --show-current

Check changed files:

git status

Stage a specific file:

git add step-03/day-21/README.md

Create a commit:

git commit -m "Day 21: Start GitHub workflow practice"

## What I Learned

Git branches help keep new development
work separate until it has been reviewed.

A pull request lets developers review
changes before merging them into main.
