# Day 1 Notes

## Operating System
An operating system manages the computer and allows programs to run.
Example: Windows.

## Browser
A browser opens and displays websites.
Example: Chrome or Edge.

## Code Editor
A code editor is used to write and edit code.
Example: VS Code.

## Terminal
A terminal lets me interact with the computer using commands.

## File Path
A file path shows the location of a file or folder.

Absolute path:
The complete address of a file or folder.

Relative path:
The location from my current folder.

## Repository
A Git repository is a project folder whose changes Git can track.
