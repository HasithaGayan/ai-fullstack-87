# Day 2 Notes

## Terminal Commands

pwd
Shows my current folder/path.

dir
Shows files and folders in the current location.

cd
Moves into another folder.

cd ..
Moves back to the parent folder.

mkdir
Creates a folder.

New-Item
Creates a file in PowerShell.

Rename-Item
Renames a file or folder.

Move-Item
Moves a file or folder.

Remove-Item
Deletes a file or folder.

## Git Commands

git status
Shows the current Git state and changed files.

git add
Stages changes for the next commit.

git commit
Saves a local checkpoint of staged changes.

git log --oneline
Shows commit history in a short format.

git remote -v
Shows the connected remote repository.

git push
Uploads local commits to GitHub.

git diff
Shows exactly what changed inside files.

git restore
Discards an uncommitted file change.
